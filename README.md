# TF Growth Strategy

Talent Formula FY2026–29 board growth strategy site.

## Live site

https://dr-bo-kra.github.io/TF-Growth-Strategy/

## Local development

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## GitHub Pages

```powershell
npm run build:pages
```

The Pages build uses base path `/TF-Growth-Strategy/` and deploys via `.github/workflows/pages.yml` on push to `main`.
